Android install

  1. Tap Download APK above.
  2. If your phone asks, allow installs from your browser (Settings → Apps → Install unknown apps).
  3. Open the APK and tap Install. KersCord uses the same app slot as Discord, so it installs right over it. If stock Discord is a newer build than KersCord, uninstall stock first, then install KersCord.
  4. Open KersCord and log in however you like.

iOS

Straight talk: Apple does not allow direct installs from a website. There is no tap-to-install link for iOS like the APK above. Anything you run on an iPhone has to be signed with a certificate.

Direct install delta-style, no computer needed

Tap-to-install straight from this page using Apple's OTA install. It goes live the moment a signed IPA sits at the URL inside manifest.plist. Until then the button errors out, because there is no signed IPA yet: making one needs a decrypted Discord IPA and an Apple signing certificate ($99/yr, and Apple revokes certs regularly, so delta.bz dies for days at a time too).

Install KersCord (iOS)

After install, trust the profile in Settings → General → VPN & Device Management.

Sideload with a free Apple ID free, 7-day signing

Use Sideloadly (Windows/macOS) or AltStore on a computer: plug your iPhone in, sign the modded IPA with your own Apple ID, and install. The signature expires after 7 days, so you re-sign weekly, and a free Apple ID caps you at 3 sideloaded apps. Set up first: install Sideloadly, get the IPA, drag it in, enter your Apple ID, wait for the phone to install, then trust the developer profile in Settings → General → VPN & Device Management.

Paid Apple Developer account $99/year, 1-year signing

Same sideload flow, but the signature lasts a year instead of a week.

Jailbreak tweak needs a jailbroken device

On a jailbroken iPhone, Discord mods ship as tweaks that run inside the real app. Not sideloading, and only worth it if you already jailbreak.

There is no KersCord IPA yet. Building one needs a decrypted Discord IPA plus your own signing identity, so the iOS section above is the route, not a download.
